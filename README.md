# 5 Things to Know About Rattlesnakes and Their Babies

A simple HTML and CSS webpage recreating an educational article about rattlesnakes. Created for a web development class using the files exported from CodingRooms.

## Files

- `index.html` — webpage and article content
- `styles.css` — webpage styling
- `UniversityLogo.png` — University of Arizona logo
- `SnakeBite.jpg` — article image

## View locally

Download the repository and open `index.html` in a browser. No installation or build tools are required.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload the four website files plus this README and `.gitignore` to the repository root, then commit.
3. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Once GitHub Pages completes deployment, use the URL shown in the Pages settings.

Keep image filenames and capitalization exactly as written in `index.html`.
